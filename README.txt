HADHANI KIDS — demo website
===========================

Files:
- index.html: responsive multilingual demo website
- assets/brand-world.png: generated visual concept artwork (if included)

How to preview:
1. Keep the assets folder beside index.html.
2. Open index.html in a modern browser.
3. For best results, use a simple local web server (for example: `python -m http.server 8000`) and visit http://localhost:8000.

Included:
- English / Russian / Kazakh interface switch
- Learning topic cards and adventure map
- First-word cards with browser speech synthesis (English pronunciation)
- Picture-choice mini game and star counter
- Parent information modal
- Responsive mobile layout

Important:
This is a functional front-end prototype, not a production-ready hosted service.
Before public launch, add secure backend accounts, persistent child progress with parental consent,
content management, accessibility and device testing, privacy policy, and domain/trademark checks.
